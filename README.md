Data Analyst and Data Scientist
-------------------------------

I earned a bachelor's degree in business analytics, where I acquired statistical skills for working with data and analyzing it using BI tools and the programming languages Python, R, and SQL. Currently hold a master's degree in data science. Built and evaluated models across classical ML and deep learning, including Random Forest, XGBoost, LSTM and CNNs, with a master's thesis on time series forecasting of realised volatility using high-frequency data. In addition, I have an experience in building cloud data pipelines and integrating foundation models through APIs. Comfortable preparing data, engineering features and presenting results clearly.
